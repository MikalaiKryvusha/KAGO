## 3. Ограничения машины и владельца

- **Карта — синглтон и предмет испытаний.** Пишет в неё ОДНА сессия, только при владельце
  (Q4 интервью 017). Замок — на доске команды + `npm run watchdog -- --status`.
- Прочие синглтоны: порт дашборда `127.0.0.1` · боевой журнал `runs/sweep/journal.jsonl`
  (память проекта: `resumeState` при живом прогоне ЗАПРЕЩЁН — фабрикует зависание) · контур
  согласований (один сервер на страницу).
- CPU/RAM (8 ядер / 32 ГБ) выдержат 3–4 параллельные сессии; узкое место — ВНИМАНИЕ владельца
  (вечера) и токены сессий, не железо.
- Мораторий Q1: новые контуры машинерии не открываются — значит, второму инженеру ПЛАТИТЬ НЕЧЕМ.

**Рекомендация — 3 места** (сложность средняя-высокая → вилка 3–6, берём нижний край: каждое
место оплачено, лишние срезаны анти-паттернами):

|---|---|---|---|
| **менеджер** (+ обязанности архитектора) | главная копия `d:\work\ai_sandbox\KAGO` | видение → задачи → merge; ЕДИНСТВЕННОЕ место с правом трогать карту, и только при владельце; STATUS, доска, интервью | живые вечера + координация и есть его независимый поток |
| **инженер** | worktree `KAGO-team-engineer` | ТОЛЬКО офлайн-машинерия: спасатель (после ответа фазы 1), хвост plans/41, черновик plans/53, санитария S3, баги 51/56 | недели офлайн-работы, существующей без выдумывания; батарея самопроверок офлайн по построению |
| **контролёр** (qa-verifier) | worktree `KAGO-team-verifier` | вердикт до КАЖДОГО merge; ре-прогон батарей; охота на ложный [TESTED] и свежесть маркера | 65 % багов — своя машинерия; 10 сорванных прогонов; независимость судьи — канон |

**Подчинение:** инженер → менеджеру · контролёр → менеджеру · менеджер → владельцу.
**У владельца остаются:** запуск живых прогонов своим словом · развилки видения · состав команды.

**Отклонено с причиной:** второй инженер (мораторий: параллельной машинерии на два места НЕТ —
анти-паттерн «взрыв агентов») · отдельный архитектор (одноавторская машинерия — складывается в
менеджера) · дизайнер (UI ниже среднего порога, облик принят владельцем).

**Прайс на входе (канон Q5 = A):** развёртывание ~1 сессия (конституция, доска, инструменты,
worktree, инструктажи) · далее — токены двух дополнительных сессий и внимание владельца на два
лишних окна · очередь аудита §7 НЕ двигается: живые вечера остаются главными, команда снимает с
них офлайн-хвосты. Отказ от команды ничего не ломает — проект продолжит жить одной сессией.

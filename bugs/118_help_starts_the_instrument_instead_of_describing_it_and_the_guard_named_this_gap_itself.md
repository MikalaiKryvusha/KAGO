# Bug 118 — `--help` ЗАПУСКАЕТ прибор вместо того, чтобы его описать. Сторож назвал эту дыру сам, и она сработала за сутки

**Статус:** 🟡 ЧАСТИЧНО (опасность у полигона снята, класс открыт) · **Тяжесть:** S2 (потерян прогон и
минуты; карте не вредит — но в классе есть приборы, которые в карту ПИШУТ) ·
**Найден:** 2026-09-08 11:19, сессия 90, при исполнении `plans/91` Ш5 — прогоном, не чтением.

## Вектор цели

**Тип: Avoid.** Не допустить, чтобы попытка УЗНАТЬ о приборе его ЗАПУСКАЛА. Хотим: `--help` у любого
прибора печатает справку и выходит, и это держат ворота, а не память агента.

## Симптом

```
$ node automation-engine/lib/polygon.mjs --help
<ничего не печатает, управление не возвращает>
```

Через две минуты в списке процессов:

```
11:19:01  node automation-engine/lib/polygon.mjs --help
11:21:21  node engine.mjs --sweep --card virtual --twin-card ...
11:21:22  node fuse.mjs --judge ...
11:21:22  node death-watch.mjs --beat-sender ...
```

**Полигон запустил пакет из пяти виртуальных карт.** Снят `taskkill /T`, шесть процессов.

## Причина — прочитана, а не предположена

`automation-engine/lib/polygon.mjs:433`, блок входа:

```js
const argv = process.argv.slice(2);
if (argv.includes('--selftest')) process.exit(cmdSelftest());
const batch = runBatch({ count: num('--count', 5), ... });   // ← сюда проваливается ЛЮБОЙ аргумент
```

`--help` не обрабатывается вовсе; любой неизвестный флаг проваливается в `runBatch` с умолчаниями.

## 🔴 ГЛАВНОЕ: СТОРОЖ НАЗВАЛ ЭТУ ДЫРУ СВОИМ ЖЕ ОБЪЯВЛЕНИЕМ, И ЕЁ НИКТО НЕ ПРОЧИТАЛ

`tools/help-guard.mjs`, поставлен накануне (сессия 89, коммит `5bc33e0`):

```
GAP: судятся только приборы с ПРИЗНАКОМ СЕРВЕРА (`createServer` или `.listen(` в тексте).
```

**Дыра названа автором сторожа заранее, вслух, в машинно-читаемом поле — и сработала меньше чем
через сутки.** Это второй случай ровно того же в проекте: строка `GAP` предохранителя от 28 августа
(«двойник не может заморозить свой хост») сняла бы инцидент 30-го и не была прочитана.

**Урок класса:** поле `GAP` — это НЕ оправдание сторожа, а ОЧЕРЕДЬ РАБОТ. Написанный `GAP`, которого
никто не превратил в тикет, отличается от ненаписанного только тем, что потом стыднее.

## Опись класса — снята машинно, а не оценена

```
приборов с CLI: 77 · отвечают на --help: 8 · НЕ отвечают: 69 · без CLI: 4
```

**69 приборов из 77.** Среди них есть безобидные (линтеры, отчёты) и есть те, у кого запуск вместо
справки означает ЗАПИСЬ В КАРТУ:

| опасные при слепом запуске | что делают |
|---|---|
| `automation-engine/lib/vf-step.mjs` | ступень кривой — пишет в карту |
| `automation-engine/lib/profile-manager.mjs` | применяет профиль |
| `automation-engine/lib/nvapi.mjs` | мост к NVAPI |
| `automation-engine/lib/ladder-descent.mjs` | спуск по лестнице |
| `automation-engine/lib/watchdog.mjs` · `fuse-rescue-hand.mjs` | руки спасения |

Полный список — в разборе сессии; воспроизводится одной командой (см. AC2).

## 🔴 ПОЧЕМУ КЛАСС НЕЛЬЗЯ ЗАКРЫТЬ ТЕМ ЖЕ СПОСОБОМ, ЧТО СЕРВЕРЫ

Сторож справки судит **ПРОГОНОМ под таймаутом** — и для серверов это правильно: только прогон
докажет, что сервер отпустил порт. **Для приборов, пишущих в карту, прогон запрещён:** проверка
«отвечает ли на `--help`» не смеет оказаться записью в GPU.

Отсюда развилка, решённая внутри машинерии: **класс закрывается СТАТИЧЕСКОЙ проверкой** — блок
входа обязан обработать `--help` ДО первой работы, и это читается разбором текста, а не запуском.
Прогонный сторож остаётся для серверов, где статика не докажет освобождение порта.

## Критерии приёмки

- **AC1.** `polygon.mjs --help` печатает справку и выходит кодом 0, не запуская пакет.
  *Проверка:* `node automation-engine/lib/polygon.mjs --help` — код 0, в `benches/runs/` не появилось
  новых песочниц. ✅ **ВЗЯТ 2026-09-08.**
- **AC2.** Опись класса воспроизводится командой, а не памятью.
  *Проверка:* сторож печатает число приборов без `--help` и их список.
- **AC3.** Статический сторож в `npm run check`: блок входа прибора обрабатывает `--help` до первой
  работы.
  *Проверка:* мутация «убрать ветку `--help` у любого прибора» → ворота красные.
- **AC4.** Долг разложен: 69 приборов чинятся не одним коммитом, а списком с отметками; тикет
  закрывается, когда список пуст.
- **AC5.** Правило «написанный `GAP` заводит тикет» стоит в каноне, а не в памяти агента.
  *Проверка:* `AGENT_GUIDE.md` или сторож угроз требует, чтобы непустой `GAP` имел ссылку на тикет.

## Решения, принятые без владельца

- **Починить сейчас только полигон.** Он держал шаг `plans/91` Ш5; остальные 68 — отдельная работа,
  и часть из них опасна при слепом прогоне. Чинить весь класс посреди чужого плана значило бы
  «починить три вещи по дороге», что канон починки прямо запрещает.
- **Класс закрывать статикой, а не прогоном** — довод выше: прогон у приборов, пишущих в карту,
  сам является тем, чего мы избегаем.

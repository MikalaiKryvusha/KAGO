# Баг 93 — у прогона нет своего журнала, оператор ставит конвейер, и код выхода гибнет

**Статус:** 🔴 ОТКРЫТ · **Заведён:** 2026-08-31 (сессия 73) · **Найден:** мной, на себе, дважды за
вечер · **Цена:** `bugs/67` заводился ровно затем, чтобы остановка спасением была видна МАШИНЕ
кодом возврата. Сегодня оба живых прогона отдали код **0**, хотя второй остановлен спасением.

---

## Симптом

Я запускал прогон так (и так же поступит любой оператор, которому нужен журнал на диске):

```
npm run engine -- --sweep ... | tee runs/sweep-session73.log
```

Код выхода такого конвейера — это код **`tee`**, а не движка. Оба прогона отчитались `exit code 0`;
второй при этом кончился строкой:

```
ОСТАНОВЛЕНО (fuse-rescue): АПВ НЕУСПЕШНО — аварийная защита не смогла вернуться на пост
```

то есть **ненулевым по существу.** Различитель, ради которого закрывался `bugs/67`, был стёрт
командой запуска.

## Корневая причина — НЕ в конвейере

Конвейер здесь следствие. Причина: **прогон не пишет собственного журнала.** Оператору нужен файл
(разбор, эстафета, форензика), файла нет — значит появляется `tee`, а с ним гибнет код возврата.
Дефект в отсутствующей возможности, а не в привычке оператора.

Это тот же класс, что `bugs/37` и `bugs/78`: улика, которая существует только пока кто-то её
перехватывает, — не улика.

## Почему это опаснее, чем кажется

`bugs/67` закрывался с формулировкой «отказ, невидимый машине». Сегодня он снова невидим машине —
**через другую дверь**. И заметил я это не по коду выхода, а прочитав последнюю строку глазами.
В автономном цикле (`/nightloop`, `/dayloop`) глаз нет: цикл прочитал бы `0` и пошёл дальше,
считая вечер удачным.

## Починка (очевидная, но НЕ начатая — сначала планы)

**`--log <файл>`: движок пишет свой вывод сам,** оператор не ставит конвейер, код возврата доходит
до вызывающего. Второй слой — рельс в `GPU_TUNING_RAILS.md` §2: команда прогона печатается БЕЗ
`tee`, с `--log`.

⚠️ **Не сторож на «отсутствие `tee`»:** сторожу неоткуда узнать, как его запустили. Лечится
устранением ПРИЧИНЫ (файл есть — конвейер не нужен), а не надзором за симптомом.

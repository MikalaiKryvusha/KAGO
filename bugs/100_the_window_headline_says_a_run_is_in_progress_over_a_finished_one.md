## Причина — прочитана в коде, не предположена

`assets/dashboard/_wiring.js` → `paint()`: на любом пульсе, кроме `noRun`, стоит
`head('Выполняется автоматический тюнинг-прогон видеокарты')` — без ветки по `r.finished`. `frame()`
меняет шапку только при обрыве связи и при `noRun`. Заголовок вкладки (`document.title`) ветку по
`finished` при этом ИМЕЕТ («KAGO — прогон завершён») — то есть одна страница говорит вкладкой одно,
шапкой другое.

Класс — **EXP-0078**: подпись над не тем состоянием — самая дешёвая ложь прибора. Тот же класс
закрыт в ту же ночь у подписи виджета кривой (`cbe4f51`): «нет прогона · завершён · ступень отмечена».

## Починка (предложение, не сделано)

1. В `paint()`: `head(r.finished ? 'Прогон завершён — окно ждёт следующего' : 'Выполняется автоматический тюнинг-прогон видеокарты')`.
2. Блок в `run-dashboard.mjs --selftest` по тексту собранной страницы: ветка `finished` у `head(` в
   `paint` есть (вызов, а не упоминание — как у блоков часов); мутация — снять ветку → красный.
3. Пересобрать `assets/dashboard/sweep.html` (`node tools/build-dashboard-page.mjs`), снимок превью
   над завершённым пульсом — глазом.

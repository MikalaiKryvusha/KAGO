## Симптом

```js
const { parseBurnName } = await import('../../tools/hold-vs-raise.mjs');
```

Импорт исполнил CLI прибора: он увидел `--selftest` в `process.argv` вызывающего, прогнал СВОЙ
набор и вызвал `process.exit`. Набор `vfstep` умер, не напечатав ни одного своего блока.

## Корневая причина

На верхнем уровне модуля стояло голое:

```js
const argv = process.argv.slice(2);
process.exit(argv.includes('--selftest') ? selftest() : report());
```

Модуль ES исполняется при импорте целиком. Значит любой импорт = чужой прогон + `process.exit`.
И `process.argv` принадлежит ВЫЗЫВАЮЩЕМУ — прибор читает чужие флаги как свои.

## Почему это опаснее обычной неаккуратности

**Дефект наказывает за правильное поведение.** Канон требует не плодить вторую копию разбора
(`PHILOSOPHY.md` → DRY; пара «правда ↔ зеркало» расходится молча). Сессия, попробовавшая
переиспользовать и получившая непонятный обвал, сделает ЕСТЕСТВЕННЫЙ вывод — «импортировать
нельзя» — и напишет копию. То есть дефект производит именно те пары, от которых проект защищается.

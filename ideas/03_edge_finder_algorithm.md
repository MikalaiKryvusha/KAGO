Переписываем алгоритм поиска края в движке KAGO согласно следующим требованиям Николая:



1) Есть профили. Они ассоциированы с JSON обектом, в котором записаны данные профиля и есть ссылка на JSON - тюнинг кривая видеокарты компа.

2) JSON объект VF кривой тюнинг видеокарты компа содержит свойства и объекты, описывающие видеокарту и точки VF кривой видеокарты ВО ВСЕМ ДИАПАЗОНЕ ЕЕ частот.

3) У видеокарты спрашивается полная сетка с минимальным шагов всех напряжений, которые она может обеспечивать - сохраняется в отдельный JSON словарь возможных напряжений видеокарты

4) У видеокарты спрашивается полная сетка с минимальным шагов всех частот, на которых она может работать - сохраняется в отдельный JSON словарь возможных частот видеокарты

5) В JSON VF кривую тюнинга видеокарты загружаются стоковые точки напряжение-частота в виде объектов. Есть частота, напряжение, статус, дата, когда точка в последний раз редактировалась.

6) Запускается процесс тюнинга видеокарты. Он работает по массиву возможных частот видеокарты с минимальным шагом от наивысшей часттоты вниз до самой малой частоты.

7) Ставится частота. ОНА ФИКСИРУЕТСЯ В ВИДЕОКАРТЕ. ВИДЕОКАРТА БЛОКИРУЕТСЯ РАБОАТЬ ИМЕННО НА ЭТОЙ ЧАСТОТЕ И НИ НА КАКОЙ ДРУГИЙ НИ ПРИ КАКИХ УСЛОВИЯХ.

8) Ставистся стоковое напряжение

9) Запускается прожиг расчетами. Корректность расчетов проверяется оракулом на появление отказок. Напряжение фиксируется в точку как кандидат храповиком. Прожиг длиться 10 секунд. Если комп не завис и работает дальше. Точке обновляется статус, что такая то дата, точка проверена, работает, доказано коротким прожигом.

10) Снижается напряжение на шаг ниже.

11) Повторяются шаги 8 - 11 пока комп не зависнет, или пока оракул не начнет замечать ошибки расчетов.

12) Комп или перезагружается, или оракул останавливает прожиг. Точка фиксируется на 10 мв више той, на которой слушился отказ. Статус - протестирована, край найден!

13) Из массива частот берется следующая вниз частота с минимальным шагом. Видеокарта на нее залачивается. Повторяются шаги 7 - 13.


14) Все выше повторяется. пока для всех частот не найдены минимальные стабильные напряжения, при которых отказов еще не было.


15) ПО итогу получается набор VF кривой, край найден. Остается его верифицировать длительными прожигами. Крайние точки прожигаются по 3 минуты каждая. Видеокарта лочится на частоту и напряжение и прожигается в каждой точке. Если отказов нет - точки фиксируются как доказанные длительным прожигом. Если есть отказ. Напряжение точки повышается еще на 10 мв. Прожигается, пока не станет сстабильной на прожиге в этой точке в 3 минуты.


16) Профиль МАКСИМАЛЬНАЯ ПРОИЗВОДИТЕЛЬНОСТЬ - без лимита мощности, без лимита частоты, карта работает с найденной VF края.

17) Профиль ОПТИМУМ -лимит мощности для 5070 Ti = 250 Вт., без лимита частоты, карта работает с найденной VF края.

18) Профиль ХОЛОДНЫЙ ТИХИЙ -лимит мощности для 5070 Ti = 250 Вт.,лимит частоты на 10% ниже максимальной возможной чаастоты видеокарты, карта работает с найденной VF края.

# Идея 14 — счётчик приёмки: `npm run curve -- --progress` и строка доставки сессии

> **Родитель:** `ideas/13` (заказ аудита) · критерий приёмки владельца — `GOAL.md` → «🏁 КРИТЕРИЙ ПРИЁМКИ ТЮНИНГА»
> **Статус:** 🟡 предложена — идея агента, требует «да» владельца до реализации
> **Наружу:** после «да» — обычная задача беклога (тяжесть лёгкая, ~полсессии с самопроверкой)

## Вектор цели

**Боль:** у проекта нет общего счёта — ни одна сессия не открывается и не закрывается расстоянием до
приёмки, поэтому вектор цели сессии сползает на последнюю боль (аудит, лицо Д1). **Куда хотим:** одно
число, одинаково читаемое владельцем и агентом, печатается одной командой и стоит первой и последней
строкой каждой сессии. **Тип цели:** Achieve (новый прибор) + Maintain (число обновляется только
командой — по образцу правила батареи).

## Что делает команда

`npm run curve -- --progress` — только чтение, карту не трогает:

```
ПРИЁМКА: краёв 11/389 (прожигом 11 · соседкой 22 · выведено 0) · не тронуто 302 · режимов отгружено 0/4
```

- «край» считается по закрытому словарю происхождения владельца (`GOAL.md`, четыре способа:
  прожигом · соседкой · интерполяцией · экстраполяцией); строка без происхождения края в счёт не идёт;
- «режимов отгружено» — из хранилища профилей: режим считается отгруженным, когда его черновик
  перестал отказывать и прошёл квалификацию;
- выход машиночитаем (`--json`) — для судьи и для строки доставки.

## Критерии приёмки

| # | Критерий | Прибор | Цель |
|---|---|---|---|
| 1 | Команда печатает счёт без записи в карту и в документ | журнал прожигов + diff документа | 0 записей |
| 2 | Счёт совпадает с ручным разбором `curves/measured.json` | сверка на текущем документе | вручную: краёв 11, не тронуто 302 — совпасть |
| 3 | Мутация «считать выведенное прожжённым» краснеет | самопроверка `curve` | ≥1 блок на подмену происхождения |
| 4 | Строка доставки входит в открытие/закрытие сессии | STATUS следующих сессий | строка присутствует |

## Границы

Ничего сверх счётчика: ни порогов, ни вердиктов, ни остановок — это прибор, не сторож (урок
`bugs/27`: тревога, врущая по расписанию, отменяет сама себя; здесь тревог нет вовсе).
